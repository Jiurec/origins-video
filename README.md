# origins-video

**13.8 Billion Years in 5 Minutes**: a 5-minute video about how life began on Earth, from the Big Bang to today.

Everything is generated by code: the visuals with Python (numpy + Pillow), the music with a small numpy
synthesizer, and the final video with ffmpeg. No stock footage or samples are used.

**Watch:** [`origins.mp4`](origins.mp4) (1920×1080, 30 fps, 5:00, stereo AAC)

## What's on screen

- **Title card for every phase**: phase number, name, date, a one-to-two-line description, and a
  "did you know" fact that fades in partway through.
- **Timeline bar** (bottom) running from the Big Bang to today, with a live "years ago" counter. The bar is
  linear, so the marker races at first and then crawls near the end. In the last 100,000 years a
  zoomed-in second bar appears to show how tiny that slice really is.
- **Cosmic Calendar** (top right): Carl Sagan's idea of squeezing the history of the universe into
  one year. The Sun forms on Sep 1, dinosaurs appear on Dec 25, and writing appears at 23:59:48 on Dec 31.
- **Ending**: the camera zooms out from Earth until it's a pale blue dot, with the line *"Every atom in you
  was made in a star."*

## Building it yourself

Requirements: Python 3.10+, `numpy`, `Pillow`, `ffmpeg`, and the Inter and Caladea fonts
(see `origins/overlay.py`).

```bash
./build.sh              # about 15–20 minutes on 4 cores; writes origins.mp4
JOBS=8 ./build.sh       # more parallel workers

python3 -m origins.render --still 150 --out frame.png   # preview a single frame (time in seconds)
python3 -m origins.music build/soundtrack.wav           # soundtrack only (~30 s)
```

## Code layout

| File | Purpose |
|---|---|
| `origins/timeline.py` | Every phase: timing, on-screen text, dates, years-ago counter, Cosmic Calendar math |
| `origins/fx.py` | Rendering toolkit: glow, particles, gradients, noise, globe renderer, world map |
| `origins/shapes.py` | Silhouettes: dinosaurs, humans, trees, gears… |
| `origins/scenes_cosmic.py` | Intro, Big Bang, first stars, solar system, Hadean Earth |
| `origins/scenes_life.py` | First cells → first humans |
| `origins/scenes_human.py` | The last 100,000 years and the finale |
| `origins/overlay.py` | Title cards, timeline bar, Cosmic Calendar, titles (crisp 1080p text) |
| `origins/render.py` | Composites frames and pipes them to ffmpeg |
| `origins/music.py` | The synthesizer and the score |

To change any text, edit `origins/timeline.py` and re-run `./build.sh`.
